Wetterstudio Çolaklı – Version 11

Neu in Version 11:
- Für Sonne, Wolken, Regen, Wind, Gewitter und Hitze gibt es jeweils eine animierte Moderator-Datei.
- Die App wählt die passende Animation anhand der aktuellen Wetterdaten.
- Der bestehende Wettermoderator, seine Sprüche und alle Wetterfunktionen bleiben erhalten.

Installation:
1. Alle Dateien aus diesem Ordner direkt in das Hauptverzeichnis des GitHub-Repositorys hochladen.
2. Vorhandene Dateien ersetzen und neue GIF-Dateien hinzufügen.
3. Commit changes ausführen.
4. Die PWA vollständig schließen und erneut öffnen bzw. die Website neu laden.

Hinweis: Die GIFs animieren die jeweilige Figur durch dezente Bewegungsphasen. Die Accessoires sind im Motiv enthalten, bewegen sich aber nicht unabhängig voneinander.
